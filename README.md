# Gestor de Inventario en Python

Este programa es básicamente una herramienta de consola hecha en Python, pensada para llevar el control de los productos y el stock de una tiendita de forma súper sencilla. La idea principal detrás de esto es poner en práctica lo básico de la programación, como usar listas paralelas, ciclos, condicionales y funciones propias, sin complicarse la vida con bases de datos ni librerías externas que requieran instalaciones raras. 
                                                                                                                                                                      # Requisitos previos
Para poner a funcionar este programa en tu computadora, solo necesitas:
1. Tener instalado **Python** (versión 3.x recomendada).
2. Una terminal de comandos (CMD, PowerShell o la terminal de tu editor de código).

---

# Paso a paso para utilizar el programa

# Paso 1: Guardar el archivo
Copia todo el código fuente del gestor de inventario y guárdalo en un archivo de texto plano llamado main.py dentro de una carpeta en tu computadora.

# Paso 2: Abrir el proyecto
Abre tu editor de código preferido (como VS Code) y carga la carpeta donde guardaste tu archivo para tener todo a la mano.

# Paso 3: Ejecutar el programa
Abre la terminal integrada en tu editor o en tu computadora, asegúrate de estar ubicado en la carpeta del proyecto y dale al botón para correr el programa (o escribe python main.py) para ver cómo el programa cobra vida en pantalla.
